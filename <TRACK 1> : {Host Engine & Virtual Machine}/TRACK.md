# <TRACK 1> : {Host Engine & Virtual Machine}

## Scope & Invariant

The host compiler, balanced ternary virtual machine, process scheduler, and test harness.

- `src/core/`: Boundaries, Cell, 32-Trit Word, 4-Directional Reel, MMIO, Linguistics.
- `src/runtime/`: Assembler, Transactional Environment, Evaluator.
- `src/terminal/`: Multi-Track OmniScheduler, Living TerminalSession, Studio Renderer.
- `src/ai/`: Cognitive loop, AI Cortex, AILearner, AIMemory, Biblical Lexicon.
- `src/parser/` & `src/ast/`: Directional Lexer, recursive-descent Parser, AST.
- `src/diagnostics/`: Restorator, Debugger, Linter, Logger, Hover Engine.
- `tests/`: 3-tier automated test harness (unit, integrated, functional).
