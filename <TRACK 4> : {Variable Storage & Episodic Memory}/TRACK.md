# <TRACK 4> : {Variable Storage & Episodic Memory}

## Scope & Invariant

The AI model's persistent brain: episodic memory bank, runtime telemetry, and permanent knowledge vaults.

- `storage/scrolls/log/`: Traditional telemetry (`.log`), partitioned by domain (`character/`, `number/`, `sessions/`, `cortex/`).
- `storage/scrolls/scroll/`: Native 4-Block episodic traces (`.scroll`), partitioned by domain (`character/`, `number/`, `sessions/`, `cortex/`).
- `storage/data/`: Permanent immutable documentation vaults and structured datasets.
