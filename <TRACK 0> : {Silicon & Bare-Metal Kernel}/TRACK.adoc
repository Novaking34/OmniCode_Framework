  Ancient Landmark.
* *Footprint:* Exactly 512 bytes (Sector 0), sealed with the sacred boot
  signature bytes `0xAA55` at offsets 510-511. If those two bytes are absent,
  every BIOS on earth refuses to boot from the device.
* *Trit Capacity:* 8 trits (stem:[3^8 = 6{,}561] discrete cognitive states).
* *Role:* Cold-metal attestation, ALU truth validation, and autonomous

* *Footprint:* 2,048 bytes (4 contiguous disk sectors).

* *Role:* Opens the A20 address line (breaking the 1 MB real-mode ceiling),

[NOTE]

*What is the A20 Gate?* In early IBM PCs, the CPU had only 20 address

A tripwire is an automated hardware or software sensor that detects an

#define TRIPWIRE_SAFE_MODE_REQUEST  0x0004  // Key held / NVRAM flag set
#define TRIPWIRE_SIMULATION_TEST    0x0005  // Automated test harness tripwire

. *Inscribe Event:* Writes `EVT_SAFE_MODE` and `EVT_CASCADE_DOWN` with the

== Proving Truth on Bare Silicon: The Balanced Ternary Test

Before OmniCode executes a single process tape or user instruction, Track 0
forces the physical CPU to prove that its arithmetic is sound.

=== What Is Balanced Ternary?

Most computers operate in binary: every value is composed of bits, each of
which is either 0 or 1. OmniCode uses *balanced ternary*: every value is
composed of trits, each of which is either -1, 0, or +1. This system has a
natural zero point and an elegant symmetry -- positive and negative values
are mirror images of each other.

The foundational axiom -- the thing that must be true before anything else
can be trusted -- is zero-sum equilibrium:

[stem]
++++
(+1) + (-1) = 0
++++

If a physical CPU cannot correctly prove this equation in hardware, then
every subsequent calculation it performs is built on a lie.

=== The Silicon Proof

In assembly language, the kernel performs this verification directly in CPU
arithmetic registers before any user code or AI reasoning is allowed to run:

[source,nasm]
----
    mov bx, 1       ; <1>
    mov cx, -1      ; <2>
    add bx, cx      ; <3>
    test bx, bx     ; <4>
    jnz hang_fault  ; <5>
----
<1> Load the positive trit (+1) into register BX.
<2> Load the negative trit (-1) into register CX.
<3> Add them together in the CPU arithmetic unit -- the result must be zero.
<4> Test whether register BX is zero (sets the Zero Flag if true).
<5> If the result is NOT zero, the physical hardware is corrupt -- halt immediately.

If the CPU computes anything other than zero, Track 0 immediately halts,
refusing to allow corrupted silicon to execute user code or cognitive
reasoning. MilleniumOS will not build on a broken foundation.

runs on a runtime, which runs on C++, which runs on Linux, which runs on a
hypervisor, which runs on firmware, which was written by engineers who trusted
the silicon manufacturer's word that the CPU arithmetic is correct.

When something breaks, nobody knows which layer failed.

*OmniCode starts at the bedrock.*

| Dimension | Conventional Computing | MilleniumOS Track 0 |
|:---|:---|:---|
| *Starting Point* | High-level languages, host OS, hypervisors | Track 0, Sector 0, bare silicon |
| *Arithmetic Proof* | Assumed from silicon manufacturer | Verified directly: stem:[(+1) + (-1) = 0] |
| *Boot Architecture* | Fragile, monolithic, single-point-of-failure | Resilient 4-Rung bidirectional ladder |
| *Failure Response* | Panic, lockup, blue screen | Controlled descent, live telemetry, watchdog |
| *Cognitive Bridge* | Gigabytes of cloud runtimes | Direct bare-metal CPI-SI substrate |
| *Civilizational Range* | Requires broadband and infrastructure | Boots from a 1.44 MB floppy, anywhere, any era |

By fitting its primordial inception core into less than 15 KB -- capable of
booting from a 1.44 MB magnetic floppy disk -- and proving mathematical
balance in bare silicon before evaluating a single user thought, Track 0
ensures that the entire cognitive pyramid above it rests on solid rock.

This is not engineering for the sake of cleverness. This is engineering for
the sake of truth. A system that cannot prove its own arithmetic before it
reasons is not a system that can be trusted. Track 0 makes that proof
non-negotiable.
