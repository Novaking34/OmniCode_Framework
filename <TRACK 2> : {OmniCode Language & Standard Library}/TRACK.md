# <TRACK 2> : {OmniCode Language & Standard Library}

## Scope & Invariant

The native OmniCode language universe, vocabulary, operators, standard modules, and Genesis boot covenant.

- `lib/core/`: Living standard library (arithmetic, logic, vectors, memory vessels, cell tapes).
- `lib/kernel/`: Genesis OS boot covenant ribbons (`boot.omni`, `boot.tape`).
- `lib/lexicon/`: Canonical vocabulary (8 parts of speech: nouns, pronouns, verbs, adjectives, adverbs, prepositions, conjunctions, interjections) and operators (`boot_kernel`, `casting`, `polarity`).
